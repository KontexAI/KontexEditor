KontexEditor

A rich-text editor you embed with one script tag. Built on TipTap/ProseMirror, MIT licensed. Source on GitHub.

Everything above is live. Try the tables (drag the borders), drop in an image, use the format painter, or turn on spell-check from the toolbar.

Embedding it

<textarea name="body"></textarea>

<script src="kontex-editor.umd.cjs"></script>
<script>
  KontexEditor.create('textarea[name=body]');
  // the textarea is hidden and kept in sync, so normal form submits work
</script>

Trimming the toolbar

KontexEditor.create('#editor', {
  toolbar: ['bold', 'italic', '|', 'bulletList', 'link', '|', 'undo', 'redo'],
});
