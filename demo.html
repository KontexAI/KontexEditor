KontexEditor

A lightweight, embeddable rich-text editor with a CKEditor-style UX — a leaner alternative to CKEditor 5.

Embeddable

Install

Plain <script> — UMD, no build step:

<script src="kontex-editor.umd.cjs"></script>
<script>
  KontexEditor.create('#editor');
</script>

npm / bundler — ESM:

npm install kontex-editor
import { create } from 'kontex-editor';

Quick start

const editor = await KontexEditor.create('#editor', {
  content: '<p>Hello world</p>',
  placeholder: 'Start typing…',
  onChange: (html) => save(html),
});

Bind to a <textarea> and it stays in sync — a normal form submit posts the HTML. Any other element is mounted into.

Options

OptionTypeDescription
contentstringInitial HTML (falls back to the textarea's value).
placeholderstringShown when empty.
editablebooleanStart editable (default) or read-only.
stickyToolbarbooleanPin the toolbar while scrolling long content.
slashMenubooleanEnable the / slash command menu (default on).
toolbarToolbarItem[]Custom toolbar layout; [] hides it.
upload{ url } | fnImage upload handler.
spellcheckbooleanDictionary spell-checker (lazy-loaded).
templatesTemplateDef[]Blocks for the Templates menu.
autosave{ key, restore? }Persist to localStorage.
onChange(html, editor)Fires on every change.
onReady / onFocus / onBlur(editor)Lifecycle callbacks.

Instance API

editor.getHTML();          // current content as HTML (store this)
editor.setHTML(html);      // replace content
editor.getJSON();          // TipTap document
editor.getText();  editor.isEmpty();
editor.focus();    editor.blur();
editor.setEditable(bool);  // toggle read-only
editor.destroy();          // unmount, restore the original element
editor.tiptap;             // underlying TipTap Editor (advanced use)

Custom toolbar

KontexEditor.create('#editor', {
  toolbar: ['bold', 'italic', '|', 'bulletList', 'link', '|', 'undo', 'redo'],
});

Items include heading, fontFamily, fontSize, bold, italic, underline, fontColor, highlight, align, lists, indent/outdent, link, image, media, table, findReplace, spellcheck, fullscreen, source, and | (separator).

Image uploads

// Endpoint: POSTs multipart form-data; respond with { url } | { location } | string
upload: { url: '/api/upload' },

// …or a custom function (S3, signed URLs, etc.):
upload: async (file) => (await myUploader(file)).url,

Framework integration

Ready-to-copy components for React, Vue 3, Svelte, and server-rendered forms are in the Integration Guide. The pattern: create on mount, call destroy() on unmount, and treat it as an uncontrolled input.

⚠️ Security: getHTML() returns raw user HTML — always sanitize it on the server (allowlist) before storing or rendering it elsewhere. The paste cleanup is a UX nicety, not a security boundary.
